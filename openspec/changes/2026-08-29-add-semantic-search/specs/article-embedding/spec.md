## ADDED Requirements

### Requirement: 記事の埋め込みベクトルを生成・保存できる
システムは埋め込み生成が要求されたとき、埋め込み未生成の記事について、タイトルおよび取得済み本文から埋め込みベクトルを生成し、`Article.embedding` に保存しなければならない（SHALL）。

#### Scenario: 未埋め込み記事の一括生成
- **WHEN** POST `/embed` が実行される
- **THEN** `embedding` が NULL の記事が対象となり、埋め込みが生成・保存され、処理件数を含むレスポンスが返る

#### Scenario: 埋め込み済み記事はスキップされる
- **WHEN** すでに `embedding` が保存されている記事が対象範囲に含まれる
- **THEN** その記事は再生成されず、API 呼び出しも発生しない

#### Scenario: 一部記事の生成に失敗する
- **WHEN** 埋め込み生成中に特定の記事で API エラーが発生する
- **THEN** その記事はスキップされ、残りの記事の処理は継続され、レスポンスに成功件数と失敗件数が含まれる

#### Scenario: 大量記事のバッチ処理
- **WHEN** 未埋め込み記事が 100 件を超える
- **THEN** 記事はバッチ単位で分割して処理され、レート制限エラー発生時はリトライされる

### Requirement: 埋め込み生成に使用したモデルを記録する
システムは埋め込みを保存するとき、使用した埋め込みモデル名を `Article.embeddingModel` に記録しなければならない（SHALL）。

#### Scenario: モデル名が保存される
- **WHEN** 記事の埋め込みが生成・保存される
- **THEN** `embeddingModel` に使用モデル名（例: `text-embedding-3-small`）が記録される

### Requirement: 埋め込み対象テキストを構成する
システムは埋め込み生成時、記事のタイトルと、存在する場合は本文（`bodyText`）を結合したテキストを対象としなければならない（SHALL）。

#### Scenario: 本文がある記事
- **WHEN** `bodyText` が保存されている Qiita 記事の埋め込みを生成する
- **THEN** タイトルと本文を結合したテキストが埋め込み対象になる

#### Scenario: 本文がない記事
- **WHEN** `bodyText` が NULL の記事（Hacker News 等）の埋め込みを生成する
- **THEN** タイトル（およびタグ）のみが埋め込み対象になり、エラーにはならない
